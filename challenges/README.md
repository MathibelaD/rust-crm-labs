# Phase Challenges

Challenges come at the end of a phase. Unlike labs, they have **no step-by-step instructions**:
just a specification, constraints, acceptance criteria and tiered hints. They show whether you
can *use* what you learned, not only follow along.

| Challenge | After | Feature |
|---|---|---|
| A | Phase 2 (Lab 10) | Duplicate customer detection |
| B | Phase 5 (Lab 20) | Weighted sales forecast |
| C | Phase 6 (Lab 24) | CSV contact import with per-row errors |
| D | Phase 8 (Lab 29) | Tags on companies and contacts |
| E | Phase 10 (Lab 36) | Teams and team-scoped authorization |

The **capstone** (Lab 41) is the final and largest challenge.

Each challenge folder contains:
- `README.md`: spec, constraints, acceptance criteria
- `hints.md`: tiered hints (direction → design → near-solution)
- `reference.md`: one possible design. Read it *after* you've finished, then compare.
